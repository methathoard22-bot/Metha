AR Hiro - เตาอบ

วิธีใช้งาน:
1. เปิด index.html ผ่าน Web Server หรือ HTTPS
2. อนุญาตการใช้กล้อง
3. หันกล้องไปที่ Hiro Marker
4. เมื่อพบ Marker จะปรากฏเตาอบ 3D
5. ปุ่ม + / - แถวแรก ปรับอุณหภูมิ 50-300°C ทีละ 10°C
6. ปุ่ม + / - แถวที่สอง ปรับเวลา 0-180 นาที ทีละ 5 นาที
7. ปุ่มเปิดเตาอบจำลองการเปิด/ปิด และแสดงแถบความร้อน
8. ปุ่มรีเซ็ตกลับเป็น 180°C / 30 นาที

หมายเหตุ:
ตัวอย่างนี้ใช้ A-Frame และ AR.js จาก CDN จึงต้องใช้อินเทอร์เน็ตเพื่อโหลด library ครั้งแรก
